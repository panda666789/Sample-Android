# 从患者记录打开会话目录

患者记录页每条记录提供“打开会话目录”按钮。点击后先显示视频位置说明：前置摄像头视频在 `front`，文件名以 `front_camera_` 开头；后置摄像头视频在 `back`，文件名以 `back_camera_` 开头。说明中显示该记录对应的完整会话路径，确认后进入目录。

目录来自 `PatientRecord.getSessionDir()`，与当前录制会话及可编辑患者信息无关。新旧患者记录均沿用其实际保存位置；不创建新目录、不复制视频、不更改采集流程。缺失、不可读取或采集根目录之外的路径显示明确提示。

优先打开声明了完整目录 MIME 类型的系统文件浏览器，避免仅声明通配 MIME 的媒体应用误接收。使用主存储的 ExternalStorageProvider document URI，无新增存储权限、无目录 URI 转授权。若系统文件浏览器不可用，则使用定位到该目录的系统视频选择器，用户选中视频后给予播放器临时读取权限。OEM 对初始目录的支持可能不同，弹窗保留完整路径作为手工定位依据。

## 验证

- 2026-10-20：44 项单元测试及 Debug 构建通过。新增 6 项测试覆盖正确记录关联、中文/空格路径、旧版记录、目录缺失、相似路径前缀、外部路径、符号链接逃逸及非目录对象。
- 小米平板 7 / Android 16：使用明确标注的临时非患者记录，从患者记录按钮打开说明，确认后到达精确的 `Session_...`；系统文件浏览器显示 `front`、`back`、`PatientInfo`，能找到合成测试视频并出现视频打开方式选择器。
- 已验证记录对应目录被移除后的提示；临时记录、合成测试视频及其目录已清理。
- 独立 Sentinel 静态复核通过；系统处理器筛选进一步要求显式目录 MIME。
- 尚未真机覆盖无目录浏览器时的视频选择器回退、其它厂商设备和放大字体场景。
